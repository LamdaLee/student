# 대전 훈련생 포털

11월 9일부터 대전 교육장 DM·AX반 훈련생이 휴대폰으로 쓰는 간단한 포털입니다. 아이디·비밀번호 없이 **처음 한 번만 개인 코드로 인증**하면 그 기기에서는 계속 쓸 수 있습니다.

## 기능

| 화면 | 내용 |
| --- | --- |
| 홈 | LMS 바로가기 버튼, 운영진이 넣은 바로가기(시간표 등), 공지, 외출·점심·출결 알림·최근 문의 요약 |
| 출결 알림 | 결석·지각·조퇴 **예정**을 날짜(오늘~60일)·시각·사유와 함께 운영진에게 알리기, 취소, 운영진 확인 여부 |
| 외출 | "지금 외출하기" → "복귀하기" 두 번 누르기. 하루 여러 번 가능, 최근 2주 기록 |
| 점심 | 오늘 갈 식당 고르기, 식당별 인원(반별)과 이름, 🎲 무작위 추천, 식당 추가(누구나) |
| 문의 | 질문 등록(공개 / 운영진에게만 비공개), 운영진 답변, 답변 여부 표시 |
| 관리 (운영진) | 날짜별 현황(출결 알림·외출·점심·다음 7일 알림), 명단 등록·개인 코드 발급, 식당 숨기기·수정, LMS 주소·공지·바로가기 설정 |

공식 출결·공가 서류는 LMS에서 처리합니다. 이 포털은 운영진에게 **미리 알리는** 용도입니다.

## 인증 방식 (한 번 인증하면 계속)

1. 운영진이 **관리 → 명단·코드**에서 `이름,반` 형식으로 명단을 붙여 넣으면 사람마다 8자리 개인 코드(예: `K7QH-3MPA`)와 초대 링크가 나옵니다. **코드는 그때만 보이므로** 전체 복사나 CSV로 받아 두세요.
2. 훈련생은 초대 링크를 누르거나 코드를 한 번 입력합니다.
3. 그 기기 브라우저에 로그인 쿠키(HttpOnly, 400일)가 저장되고, 쓸 때마다 기간이 연장됩니다. 같은 코드로 PC·휴대폰 여러 기기를 등록할 수 있습니다.
4. 휴대폰을 바꿨거나 코드가 새어 나가면 운영진이 **코드 재발급**을 누릅니다. 이전 코드와 그 사람의 기존 기기 로그인이 모두 끝납니다. **중지**하면 바로 쓸 수 없고 기록은 남습니다.

알아 둘 점:
- 아이폰에서 '홈 화면에 추가'한 아이콘은 사파리와 저장 공간이 따로라서, 아이콘으로 처음 열 때 코드를 한 번 더 입력해야 합니다.
- 브라우저 데이터(쿠키)를 지우거나 시크릿 창을 쓰면 다시 입력해야 합니다.
- 틀린 코드를 같은 IP에서 15분 동안 30번 넘게 넣으면 잠시 막힙니다(교육장 전체가 같은 IP여도 평소에는 막히지 않을 정도).

## 처음 시작하기 (Vercel)

`lunch`(런치패스)와 같은 구성입니다. Vercel 기본 주소(`프로젝트명.vercel.app`)를 쓰면 도메인을 사지 않아도 됩니다.

1. Vercel → **New Project → Import**로 `LamdaLee/student` 저장소를 가져옵니다. Framework Preset은 **Other**, 나머지는 기본값(`vercel.json` 사용)입니다.
2. **Storage → Neon(PostgreSQL)** 을 만들어 프로젝트에 연결합니다(싱가포르 지역 권장, 함수도 `sin1`). `DATABASE_URL`이 생겼는지 확인합니다.
3. **Environment Variables**에 추가합니다. 값은 비밀번호 관리자 등으로 만든 무작위 값을 쓰고, Git이나 채팅에 붙여 넣지 마세요.
   - `AUTH_SECRET`: 32자 이상. **한 번 정하면 바꾸지 마세요**(바꾸면 모든 개인 코드가 무효가 됩니다. 이미 인증한 기기는 그대로).
   - `SETUP_KEY`: 24자 이상. 최초 운영진 등록에만 씁니다.
4. 다시 배포한 뒤 주소를 열어 **최초 운영진 등록**에 `SETUP_KEY`와 이름을 넣습니다. 나오는 개인 코드는 다른 기기용으로 적어 두세요. 등록 후에는 `SETUP_KEY`를 지워도 됩니다.
5. **관리 → 설정**에서 LMS 주소, 공지, 그 밖의 바로가기를 넣습니다.
6. **관리 → 명단·코드**에서 훈련생을 등록하고, 개인 코드·초대 링크를 각자에게 전달합니다. 다른 운영진은 구분을 '운영진'으로 바꿔 이름만 넣어 등록합니다.

운영진 코드를 모두 잃어버렸다면 `DATABASE_URL`·`AUTH_SECRET`을 넣은 `.env`로 `npm run add-staff -- 이름`을 실행해 새 운영진 코드를 받을 수 있습니다.

## 로컬 실행

Node.js 22.9 이상이 필요합니다. `DATABASE_URL`이 없으면 `.local/portal.sqlite`에 저장합니다.

```bash
npm install
```

```bash
SETUP_KEY=local-test-key-1234567890 npm start
```

http://localhost:3000 을 열어 최초 운영진 등록부터 시작합니다.

## 테스트

```bash
npm test
```

PostgreSQL로도 확인하려면 **테스트 전용** DB를 `TEST_DATABASE_URL`로 지정합니다. 임시 스키마를 만들고 지웁니다.

```bash
TEST_DATABASE_URL=postgres://... npm test
```

## 구성

- `public/` — 화면(`index.html`, `app.js`, `style.css`), 홈 화면 아이콘·매니페스트
- `lib/app.js` — API 전체(인증, 출결 알림, 외출, 점심, 문의, 관리)
- `lib/db.js` — PostgreSQL / SQLite 연결과 테이블(첫 요청 때 자동 생성)
- `server.js` — 로컬 서버, `api/index.js` + `vercel.json` — Vercel 배포
- `scripts/add-staff.js` — 운영진 코드 복구용
- `test/` — API 테스트

반 목록은 `lib/app.js`의 `CLASSES`(`["DM", "AX"]`)에서 바꿀 수 있습니다.
