# 대전 훈련생 포털

11월 9일부터 대전 교육장 DM·AX반 훈련생이 휴대폰으로 쓰는 간단한 포털입니다. **런치패스와 같은 학번·비밀번호로 한 번만 로그인**하면 그 기기에서는 계속 쓸 수 있고, 점심 탭을 누르면 **런치패스도 자동으로 로그인**되어 열립니다.

## 기능

| 화면 | 내용 |
| --- | --- |
| 홈 | LMS 바로가기 버튼, 운영진이 넣은 바로가기(시간표 등), 공지, 외출·출결 알림·최근 문의 요약, 런치패스 바로가기 |
| 출결 알림 | 결석·지각·조퇴·외출 **예정**을 날짜(오늘~60일)·시각(외출은 나갈·돌아올 시각)·사유와 함께 운영진에게 알리기, 취소, 운영진 확인 여부 |
| 외출 | "지금 외출하기" → "복귀하기" 두 번 누르기. 하루 여러 번 가능, 최근 2주 기록 |
| 점심 | 런치패스(https://matzip-six.vercel.app)를 자동 로그인 상태로 새 창에서 엽니다. 식당 선택·인원 집계는 런치패스에서 그대로 합니다. |
| 문의 | 질문 등록(공개 / 운영진에게만 비공개), 운영진 답변, 답변 여부 표시 |
| 관리 (운영진) | **휴대폰 알림**(결석·지각·조퇴·외출 알림·취소, 새 문의 글·댓글), 날짜별 현황(출결 알림·외출·다음 7일 알림·반별 재적), 명단(런치패스 명단 + 포털 사용 현황, 포털 사용 중지), LMS 주소·공지·바로가기 설정 |

공식 출결·공가 서류는 LMS에서 처리합니다. 이 포털은 운영진에게 **미리 알리는** 용도입니다.

## 계정과 로그인 (런치패스 연동)

- **명단은 런치패스에만 등록합니다.** 런치패스 **운영 관리 → 이용자 등록**에서 이름·학번·반(DM, AX)을 등록하고 초기 비밀번호(숫자 4자리)를 전달하면, 그 학번·비밀번호로 포털에 바로 로그인할 수 있습니다. 포털에서 따로 등록할 것은 없습니다.
- **로그인은 포털이 기본입니다.** 첫 로그인(또는 비밀번호 초기화 후)에는 포털 화면에서 새 비밀번호를 정하고, 이 비밀번호는 런치패스에도 똑같이 적용됩니다.
- 포털 로그인은 그 기기에 400일 유지되고(HttpOnly 쿠키), 쓸 때마다 연장됩니다.
- 하단 **점심** 탭을 누르면 2분짜리 1회용 서명 토큰으로 런치패스에 자동 로그인해서 새 창으로 엽니다. 런치패스 로그인은 런치패스 규칙대로 12시간 유지되고, 다시 점심 탭을 누르면 또 자동 로그인됩니다.
- **운영진:** 런치패스 운영진(관리자)은 포털에서도 자동으로 운영진입니다.
- 이름·반·운영진 여부는 한 시간마다 런치패스에서 다시 확인합니다. 런치패스에 잠시 연결되지 않아도, 이미 로그인한 기기는 계속 쓸 수 있습니다.
- 비밀번호를 잊으면 런치패스 운영진이 **비밀번호 초기화**를 합니다. 포털의 **관리 → 명단 → 포털 사용 중지**는 포털만 막고 런치패스 계정은 그대로 둡니다.

두 앱은 **같은 Neon 데이터베이스**를 쓰지만 테이블은 나뉘어 있습니다. 런치패스는 `public` 스키마, 포털은 `portal` 스키마를 씁니다. 두 앱 모두 `sessions`·`posts` 테이블이 있어서 스키마를 나눴고, 포털은 SQL을 보낼 때 테이블 이름 앞에 스키마를 붙입니다(Neon pooled 연결에서도 안전). 스키마 이름은 `PORTAL_DB_SCHEMA`로 바꿀 수 있습니다(기본 `portal`, `public`은 허용하지 않음). 계정 확인은 런치패스 코드를 그대로 쓰도록 DB를 직접 읽지 않고, 같은 비밀값 `PORTAL_SECRET`으로 서명한 요청과 토큰만 주고받습니다. 서명 코드는 `lib/lunchpass.js`와 런치패스의 `lib/portal.js`에 같은 내용으로 있습니다.

알아 둘 점:
- 아이폰에서 '홈 화면에 추가'한 아이콘은 사파리와 저장 공간이 따로라서, 아이콘으로 처음 열 때 한 번 더 로그인해야 합니다.
- 브라우저 데이터(쿠키)를 지우거나 시크릿 창을 쓰면 다시 로그인해야 합니다.
- 틀린 비밀번호 시도 제한(10분에 15번)은 런치패스와 같은 기록을 씁니다.

## 운영진 휴대폰 알림

훈련생이 결석·지각·조퇴·외출을 **알리거나 취소할 때**, **새 문의 글**이나 **문의 댓글**을 쓸 때, 알림을 켠 운영진 휴대폰에 바로 알림이 뜹니다. 알림을 누르면 그 날짜의 현황이나 그 문의 글이 열립니다. 브라우저 표준 웹 푸시(VAPID)라서 별도 서비스 가입이나 비용이 없습니다.

**서버 설정:** 따로 할 일이 없습니다. 처음 쓸 때 포털이 알림 키(VAPID)를 만들어 DB에 저장합니다. 직접 정한 키를 쓰고 싶을 때만 `npm run vapid`로 만든 키를 `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`(선택: `VAPID_SUBJECT`)에 넣습니다. 키가 바뀌면 기존에 켠 기기는 다시 켜야 합니다.

**운영진 각자 (기기마다 한 번)**
- **안드로이드:** 크롬(또는 삼성 인터넷)으로 포털에 로그인 → **관리 → 설정 → 이 기기에서 알림 받기** → 허용 → **테스트 알림 보내기**로 확인합니다.
- **아이폰 (iOS 16.4 이상):** 사파리로 포털을 열고 공유 버튼 → **홈 화면에 추가** → 홈 화면의 포털 아이콘으로 열어 로그인 → **관리 → 설정 → 이 기기에서 알림 받기**. 사파리 탭에서는 아이폰 정책상 알림을 받을 수 없습니다.
- PC 크롬·엣지에서도 켤 수 있습니다. 카카오톡 안의 브라우저는 지원하지 않습니다.
- 알림을 켜지 않은 운영진에게는 관리 화면 위에 안내가 보입니다. 끄려면 같은 곳의 **이 기기 알림 끄기**를 누릅니다.

알아 둘 점: 꺼져 있던 휴대폰은 12시간 안에 켜지면 알림을 받습니다. 보낸 사람 본인에게는 오지 않으며, 운영진의 답변은 다른 운영진에게 알리지 않습니다. 런치패스에서 운영진 권한이 해제되면 그 사람 기기로는 더 이상 가지 않습니다.

## 처음 시작하기 (Vercel)

`lunch`(런치패스)와 같은 구성입니다. Vercel 기본 주소(`프로젝트명.vercel.app`)를 쓰면 도메인을 사지 않아도 됩니다.

1. Vercel → **New Project → Import**로 `LamdaLee/student` 저장소를 가져옵니다. Framework Preset은 **Other**, 나머지는 기본값(`vercel.json` 사용)입니다.
2. 런치패스가 쓰는 **같은 Neon 데이터베이스**를 이 프로젝트에도 연결합니다. Vercel **Storage**에서 기존 `lunchpass-db`를 이 프로젝트에 연결하거나, 런치패스와 같은 연결 문자열을 `DATABASE_URL`로 넣습니다. 포털 테이블은 같은 DB 안의 **`portal` 스키마**에 따로 만들어지고 런치패스 테이블(`public`)은 건드리지 않습니다.
3. 비밀번호 관리자 등으로 32자 이상 무작위 값을 하나 만들어, **두 프로젝트에 같은 값으로** 넣습니다. Git이나 채팅에 붙여 넣지 마세요.
   - 포털 프로젝트: `PORTAL_SECRET` = 그 값. 런치패스 주소가 기본(https://matzip-six.vercel.app)과 다르면 `LUNCHPASS_URL`도 넣습니다.
   - 런치패스 프로젝트: `PORTAL_SECRET` = 같은 값, `PORTAL_URL` = 포털 주소(예: `https://프로젝트명.vercel.app`).
4. 두 프로젝트를 모두 다시 배포합니다. 런치패스는 이 연동 코드가 들어간 브랜치를 배포해야 합니다.
5. 런치패스 운영진 계정으로 포털에 로그인해 **관리 → 설정**에서 LMS 주소, 공지, 그 밖의 바로가기를 넣습니다. 운영진 휴대폰 알림을 쓰려면 아래 '운영진 휴대폰 알림'의 키 설정도 함께 합니다.
6. 새 훈련생은 런치패스에서 **DM / AX** 반으로 등록합니다. **관리 → 명단**에서 누가 포털에 로그인했는지 볼 수 있습니다.

## 로컬 실행

Node.js 22.9 이상이 필요합니다. `DATABASE_URL`이 없으면 `.local/portal.sqlite`에 저장합니다. 로그인하려면 같은 `PORTAL_SECRET`으로 실행한 런치패스가 필요합니다.

```bash
npm install
```

```bash
PORTAL_SECRET=같은-32자-이상-값 LUNCHPASS_URL=http://localhost:3200 npm start
```

런치패스는 다른 터미널에서 실행합니다.

```bash
PORTAL_SECRET=같은-32자-이상-값 PORTAL_URL=http://localhost:3000 PORT=3200 npm start
```

## 테스트

```bash
npm test
```

PostgreSQL로도 확인하려면 **테스트 전용** DB를 `TEST_DATABASE_URL`로 지정합니다. 임시 스키마를 만들고 지웁니다.

```bash
TEST_DATABASE_URL=postgres://... npm test
```

## 구성

- `public/`: 화면(`index.html`, `app.js`, `style.css`), 홈 화면 아이콘·매니페스트
- `lib/app.js`: API 전체(로그인, 출결 알림, 외출, 문의, 관리)
- `lib/push.js`, `public/sw.js`: 운영진 휴대폰 알림(보내기 / 받아서 표시)
- `lib/lunchpass.js`: 런치패스 연동(서명, 로그인·명단 조회, 자동 로그인 토큰)
- `lib/db.js`: PostgreSQL / SQLite 연결과 테이블(첫 요청 때 `portal` 스키마와 테이블 자동 생성)
- `server.js`: 로컬 서버. `api/index.js` + `vercel.json`: Vercel 배포
- `test/`: API 테스트
